Meedoen met Remote GPU-Tests

Laat een vriend of ontwikkelaar Veltra op jouw PC testen. Bij elke start staat dit weer uit.

Automatisch herhalen staat aan Intrekken zet de testmodus uit en weer aan: een lopende test stopt en de koppelcode kan veranderen.
KoppelcodeGeef deze code aan wie de test stuurt.

Een SSH-tunnel kan ook: http://127.0.0.1:8088

  • Alleen ingebouwde tests. De relay kan alleen een test uit een vaste lijst in deze app kiezen, geen opdrachten of bestanden sturen.
  • Niets draait zonder jouw “Ja”. Een verzoek verloopt na 5 minuten.
  • Wat wordt verstuurd: processor, RAM, besturingssysteem, naam en VRAM van de videokaart, modelnaam, -bestandsnaam en -instellingen, meetresultaten en de antwoorden van het model op ingebouwde testvragen. Niet: gebruikers- of computernaam, mappen, chats. De relaybeheerder ziet je IP-adres.
